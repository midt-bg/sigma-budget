# Исторически материали

`prototype/` съдържа самостоятелния HTML прототип и инструментите за него (таг `proto-v3.6`). `mock/` съдържа проверките и сравненията на предишните версии (`mock-v1` до `mock-v6`). Те се изпълняват от съответния исторически таг, където старите пътища са запазени.

Нищо тук не се сглобява или изпълнява от CI. Публикуваните данни и действащият код са извън тази директория. Контролната сума на историческия HTML остава част от проверката на запазените входове. Нов код се добавя според ADR 0003.
